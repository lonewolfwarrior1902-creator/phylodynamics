# Viral Phylodynamics & Stochastic SIR Simulator

An interactive Streamlit application for viral evolutionary analysis and stochastic epidemic modeling.

## Features
- **Jukes-Cantor Evolutionary Distance Matrix**
- **Midpoint-Rooted Neighbor-Joining Phylogenetic Tree**
- **Root-to-Tip Molecular Clock Regression ($\mu$ and $t_{\text{MRCA}}$)**
- **Stochastic SIR Epidemic Simulation (Gillespie Algorithm)**

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
